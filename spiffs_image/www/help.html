👋 WELCOME
AtlasCube is a Wi-Fi internet radio. Stream stations, play music from an SD card or a Bluetooth source, and schedule playback — all from this web interface. The quick steps below link straight to the matching screen.
🌐 Full documentation online
1 · GET ONLINE
Connect AtlasCube to your Wi-Fi so it can stream, then set the clock.
🌐 Wi-Fi 🕐 Date & Time
2 · LISTEN TO RADIO
Pick a station, adjust volume and hit Play on the home screen. Manage your station list and shape the sound with the equalizer.
📻 Home 📝 Stations 🎚️ Equalizer
3 · OTHER SOURCES
Stream from a phone over Bluetooth, or play music files from an SD card.
🔵 Bluetooth 🎵 SD Player
4 · SCHEDULE
The Events page has two tabs. 🗓️ Events holds reminders, birthdays, name days and voice notifications. 🎵 Playback schedules the radio or an SD file (or folder) to start at a set time, with an optional stop time, daily, weekly or one-off. The big 🔔 drawn for an event that carries no graphic of its own is switched on and off at the top of the Events tab — it applies to every event.
🗓 Events
5 · MAKE IT YOURS
Tune the device screen, dim & wake behaviour, screensaver and colour theme. Rearrange the on-screen layout with the Layout Editor.
🖥️ Display 🔅 Dim & Wake 🌀 Screensaver 🎨 Theme 🖼️ Layout Editor
6 · WALLPAPERS
Every screen has its own background, set in the Layout Editor on that screen's tab. The quickest way needs no SD card: pick the screen, click Online gallery under the preview, choose a Use in slot: number and press Use in slot on a wallpaper — the device downloads it itself and shows it right away.

An internet wallpaper takes two steps, which is the usual reason nothing seems to happen: the 🌍 Internet tab only fills a slot (pick the slot, set the URL, Fetch now — a thumbnail confirms it). To see it, go back to the screen's tab and press Internet with the same slot selected. Slots live in RAM, so set Auto refresh to at least Once after boot or the slot is empty after a power cycle.
🖼️ Layout Editor 🌐 Wallpaper gallery
7 · SMART HOME
Connect AtlasCube to your home automation over MQTT — control it from a broker and build custom on-screen widgets that show or trigger your devices.
📨 MQTT 🔧 Widgets
8 · ADVANCED
File manager, file editors and hardware pin setup live under Settings → Tools; firmware updates (OTA), web UI files and settings backup are under Settings → System. These are powerful — change them only if you know why. Settings → Diagnostics shows memory, firmware and Wi-Fi state, copies it as text for a bug report, and can arm extra per-subsystem logging on the serial console while you chase a problem.
🛠️ Tools 🩺 Diagnostics ⚙️ System
